# 跨领域示例：机会成本

这是结构示范，不是每次调用都要照抄的课文。

1. **Toy sample**：周末只有一个时间段，可加班得 600 元，或上免费课。教学设定：都可行且占用整个时间段，暂不计交通和疲劳。选课的现金支出为 0，放弃的最佳替代项价值为 600 元。课程收益尚未定价，所以不能直接断定选课不划算。
2. **同类**：机会成本衡量最佳放弃项；现金支出衡量支付；沉没成本是已发生且不可收回的成本。它们观察同一决策的不同面，不能排成互斥的三种方案。若统一按净收益比较，不重复扣同一笔机会成本。
3. **类比**：一个停车位只能放一辆车：车位对应稀缺时间，候选车对应可行方案，占用对应选择，留在外面的最佳车对应放弃项。类比只表达排他占用，车辆本身不决定方案价值。
4. **完整机制链**：明确目标与时间约束 → 列出真实可行方案 → 用一致口径比较预期净价值 → 选定一个 → 找出剩余方案中最佳者 → 把它记作机会成本 → 用新信息复核。多方案时取最佳放弃项，不把所有放弃项相加。
5. **细节补充**：非金钱价值也可重要；未知收益保留未知；机会成本依赖当时的可行选项。迁移题：如果原本的加班取消，改为另一份收入 300 元的兼职，且它是最佳替代项，上免费课的机会成本是多少？参考：在相同假设和口径下是 300 元。

这里的数据流是决策机制链，无须虚构训练阶段或神经网络。贯穿同一个时间约束和选择，才有可迁移性。
