# FM 教学案例：保留讲法，校准结论

本页用来避免把学生示例的技术误解固化成通用教学规则。只在涉及这些概念时读取。

## 一个可以手算的真实子过程

**教学设定**：一维、线性条件路径、噪声端 $t=0$、数据端 $t=1$。取 $x_0=-1$、$x_1=3$、$t=0.25$。

训练时：$x_t=(1-t)x_0+t x_1=0$，该配对路径的监督速度 $u_t=x_1-x_0=4$。
若网络预测为 $v_\theta(0,0.25)=3$，这个样本的平方误差是 $(3-4)^2=1$。
这里的 4 对该人为指定路径是精确导数，不等于全体真实数据的唯一运动规则。

平方损失训练的最优回归量可理解为 $E[x_1-x_0\mid x_t,t]$，有条件生成时还要条件化到 $c$。训练配对线段的速度和学到的边缘速度场需要区分，不能说网络记住了每颗豆子的专属终点。

推理时只有新噪声、条件与网络，没有该样本的目标 $x_1$。为了演示接口，**假设网络返回值**：从 $z_0=-0.5$ 出发，步长 $0.25$；网络先返回 2，得到 $z_1=0$；再根据新状态与新时间返回 1，得到 $z_2=0.25$。这些数值只演示 Euler 更新，不是训练所得模型、已收敛采样或真机动作。

条件版本：$v_\theta(x_t,t,c)$；$c$ 可含图像、语言和本体状态。动作块 $H\times d$ 的整块候选、速度与输出形状对应。内部生成时间与机器人执行时间分开，固定条件下的多次求解不意味着每次都拍新照片。

## 易误导说法及修正

| 易误导说法 | 应保留的准确边界 |
|---|---|
| AR 天生离散，只有连续生成才是生成模型 | 自回归是一种因子分解，可建模连续变量。课堂有限词表 AR 的离散性来自编码/输出选择；AR 也属于生成建模。 |
| FM、Diffusion、RF 是互斥的三代，按步数就能区分 | FM 支持不同概率路径；RF 的线性插值速度回归与 FM 有重叠。训练目标、路径、参数化、求解器和步数是不同维度。 |
| Diffusion 永远多细步，FM 永远均匀少步 | 训练时间采样与推理离散网格分开；实际步数取决于模型、求解器、蒸馏和质量要求。 |
| π0.5 使用 RF 所以“不是 FM”；π0-FAST 属于 FM 阵营 | 具体模型归属查相应版本原始报告。FAST 是动作分词器，论文将其与自回归动作模型结合；DCT 是通用变换工具，不专属于 AR。 |
| 连续输出没有精度损失 | 可避开特定分箱量化，仍有模型误差、有限浮点精度、数值求解和控制误差。 |
| 多步必然比一步可靠，平滑就保证少步准确 | 单步生成可行；误差与场的性质、学习质量、步长等有关。不能从比喻推出速度或质量保证。 |
| 噪声是唯一能写公式的分布；每颗豆子都被打乱回原起点 | 高斯只是易采样的常见基分布。可独立采样两端或采用其他耦合；“同一颗豆子”只是配对记号。 |
| 每个位置都预测正确，生成必定形成目标形状 | 学到的是分布中的近似规则，泛化与数值误差需评估；生成末态是模型样本，不是已知真值。 |
| 轨迹交叉意味着同一个推理状态有多个确定去向 | 训练条件路径可能交叉；满足唯一性条件的确定性 ODE，在同一时刻同一状态的后续解唯一。不同初始噪声可产生多样性。 |
| 没有闭式解就不可积；热传导终会均温 | 数值求解不依赖初等原函数；连续热方程通常是 PDE，稳态依赖边界条件。位置积分还须带初值。 |
| 多样性自动保证所有生成动作合理、安全或避障 | 条件化与分布建模不提供这种保证；多样性、执行约束、候选选择和闭环反馈应分别解释。 |

## 只引用覆盖到的证据

- [Flow Matching for Generative Modeling](https://arxiv.org/abs/2210.02747)：FM、条件概率路径、向量场回归；论文不将 FM 定义为“固定均匀少步”。
- [Flow Straight and Fast](https://arxiv.org/abs/2209.03003)：Rectified Flow、直线输运目标与 reflow；少步表现依赖训练与评测设置。
- [FAST: Efficient Action Tokenization for Vision-Language-Action Models](https://arxiv.org/abs/2501.09747)：频域动作分词、自回归动作模型；token 压缩比与端到端加速倍数分开。

以上入口提供核验方向，实际生成讲解时只标注自己已经读取的段落/版本。模型细节不要从摘要外推。
