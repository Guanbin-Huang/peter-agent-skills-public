## 当前机器验收

1. 用 `sw_vers`、官方 `Contents/Info.plist` 读取当前平台和版本；若需要 Electron 版本，只读查看现有 Framework plist，不修改或重新打包。
2. 记录官方包相关文件哈希及签名检查的原结果；先确认上传和下载任务，再决定是否正常退出。当前客户端有官方深色选项时优先使用它。
3. 用新入口启动后，从进程命令行确认启动参数，并通过本机可用的原生 UI 工具获取新鲜界面。主页面、传输页、设置弹窗分别检查；不要用旧截图证明当前效果。
4. 在授权内容中实际打开图片和视频，检查颜色及播放；不启动新的云文件修改或付费行为。正常预览可能改变缓存、最近查看或播放进度。
5. 使用独立 light 入口／原版做普通启动对照，再按用户所需状态结束。命令行生成测试通过与真实 GUI 通过分别记录。

## 触发与不触发示例

- 触发：“Mac 百度网盘太白了，帮我做个夜间入口。”
- 触发：“用这个技能验证网盘升级后的深色模式，再检查能不能恢复。”
- 不触发：“帮我把文件上传到百度网盘。”（网盘文件工具）
- 不触发：“给百度网盘网页装深色主题。”（浏览器主题）
- 不触发：“Windows 百度网盘怎么改夜间模式？”（本技能未覆盖该平台）
