# 百度网盘桌面夜间模式

用独立启动器启动已安装的官方客户端，保留原程序、账号和云文件。

## 工作流

1. **确认对象和验收。** 确认运行主机为 macOS、官方应用路径、版本、当前运行状态及上传／下载任务。查看当前客户端是否已有官方深色设置，有则优先使用。读取 [已验收版本与检查方法](references/verified-version.md)，区分历史已验收版本与本机当前版本。
2. **记录原状。** 保存官方 `Contents/Info.plist`、`Contents/Resources/app.asar`、`core.asar`（存在时）的 SHA-256，记录原签名检查结果；只读检查，不解包改写或重新签名。记录普通启动的界面状态。截图与账号、云文件等证据只留本地，不提交公共仓库。
3. **生成入口。** 运行下方脚本，指定一个尚不存在的输出路径。脚本只写新启动器，不启动客户端、不自动退出应用，不修改系统外观、安全设置、账号或传输／同步配置。已有入口先检查内容并复用，不为了重跑而删除它。

   ```bash
   python3 scripts/create_launcher.py \
     --app "/Applications/BaiduNetdisk.app" \
     --output "$HOME/Applications/百度网盘夜间版.app" \
     --mode dark
   ```

   命令从本 Skill 目录执行，或改用脚本绝对路径。输出路径已存在时脚本拒绝覆盖；通过 Finder 创建桌面替身或符号链接前，同样检查桌面目标是否被占用。脚本不会创建桌面入口。
4. **正常重开。** 启动参数只作用于新进程。客户端正在运行时先确认活跃传输；有任务则保留入口、暂不重启。无活跃任务且本次用户授权包含重启时，通过应用菜单正常退出，再打开新入口；不要强杀进程。运行中再次点击入口通常只激活已有窗口。
5. **验证真实效果。** 检查主进程确实带有 `--force-dark-mode --blink-settings=forceDarkModeEnabled=true`，再回读主页面／文件列表、传输页、设置弹窗的实际深色效果与文字可读性。检查正常打开文件、图片与视频预览的颜色，不以截图像素或参数存在代替整体验收。预览仅使用用户允许查看的内容；不为验收上传、删除、重命名或分享文件。复核官方文件哈希与原签名状态未变化。
6. **验证恢复并交付。** 在独立新路径用 `--mode light` 生成普通启动副本；正常退出后打开该副本或原版，检查恢复普通启动行为。若系统／官方设置本身为深色，普通启动不保证白色。需要保留夜间模式时再次正常退出并打开 dark 入口，确认最后界面；测试恢复不要改写正式 dark 启动器。只回报实际检查的页面、当前入口与使用方式。

## 使用边界

- 仅声明当前已观察的版本与页面效果。自动深色转换不是原厂定制主题，部分装饰或线条图标可能有色差；更新客户端后重新验证参数、页面与媒体颜色。
- 发现当前版本没有效果时保留证据并正常恢复原版启动，不把已知无效参数反复试验，不自动扩展到修改安装包或系统安全设置。
- 本技能负责桌面显示，网盘文件操作交给专用网盘工具；不要将该参数组合推广为所有 Electron 应用的通用保证。
