# 多视频 Preview 快路径 v2：快处理，先验后交付

适用：用户给多个口播视频和逐字稿，或要求恢复此工作流。先阅读本文件；技术时序验收由 `clip-fine-cut-rhythm/references/音画时序验收-v2.md` 负责。本规范不增加额外“开始剪”确认，也不把技术修复变成内容重写。

## 固定顺序

1. **接收与极简初检**：收齐视频/逐字稿，记录路径和指纹，快速探测音轨、时长、方向、时间基及已应用倍速。只在解码/音轨/转录有异常时扩大检查。用户素材通常正常；不默认逐帧全面质检、OCR、美化或降噪。VFR 是正常录制特征，不按平均帧率重造原片时序。
2. **并行前处理**：唯一音频用本地 WhisperX；本地默认先 1 路，确认内存/CPU 余量后可升至 2 路，资源预算见 `任务模型与并行路由-v1.md`；有相同源指纹与参数的缓存就复用。小模型/子 agent 在各段 ASR 返回后并行产出章节、口误/重说、过度重复、现场指令和气口候选；只输出源时间、原话、理由、置信度，不改主时间线。只对码流/内容严格相同的素材复用；疑似同内容不同 take 不自动合并。
3. **主会话确定顺序并冻结唯一 EDL**：优先级是当前明确指示 > 逐字稿逻辑 > 素材顺序。当前启动卡已经 confirmed 或本轮明确给全形式/B-roll 决定时，简短告知顺序并直接继续，不重复索要“开始”；否则先完成主 skill 的只读启动卡确认，不写 EDL。用户明确说“先别剪”时停在顺序确认。真实录音决定实际说了什么，逐字稿只作逻辑地图。按当前要求处理明显重复、说错/重录与过长气口，保留字头字尾和强调，不按全部静音阈值机械碎切。冻结源区间、输出整数帧、统一倍速、音画共同裁切锚点、源指纹和 EDL 指纹。
4. **两条先验通路并行，汇合后才编码整片**：A 路生成最终音频/字词 timing、字幕和字体冒烟；独立 ASR 只对该音频版本跑必要的一次。B 路对实际渲染链运行编号帧回归及每种源时钟/变换分支的代表性长段小样（约 6–10 秒或现有最长短段），核对原片首中尾画面和音轨。小样为内部技术验证，不要求用户额外审核。源↔Preview 映射、删除摘要、HTML 外壳可与 A/B 并行，但烧字整片必须等 A、B 都通过。1 秒字体样片不能替代长段时序样片。
5. **低清 Preview → 验收 → HTML**：从干净原片一次编码带字幕的 270×480/30fps Preview，沿用已确定的速度。跑源相对时序、字幕、解码/兼容性检查；同一阶段的检查可并行。只在成功后发布版本化文件，启动/切换 HTML，再读取播放器实际媒体 URL，下载核对哈希与 Range 跳转。给用户一个已验收入口，不要求再次说“开始剪”。最终高清仍等粗剪/精剪批准。

## 依赖图（箭头是硬依赖）

```text
快速素材信息 ───────────────────────────┐
每个唯一源：提音频 → ASR → 候选（受资源限额） ├→ 主会话定序/取舍 → 冻结 EDL
逐字稿：章节逻辑 ───────────────────────┘
冻结 EDL ┬→ 最终音频 → 字幕/独立对齐 → 字体小样 ─┐
         ├→ 实际滤镜回归 → 长段音画小样 ─────────┼→ 一次 Preview 编码
         └→ 时间映射 / 摘要 / HTML 外壳 ─────────┘
Preview 编码 → 时序+字幕+解码验收 → 发布版本文件 → 实际URL字节验收 → 打开HTML
```

ASR 未返回时，不能把参考逐字稿假装成已转录文本；字幕没定稿时不能抢先烧字；未验收时不能把占位网页或临时视频宣布为完成。

## 三道硬门槛

| 门槛 | 时机 | 失败处理 |
|---|---|---|
| 实际滤镜小样 | 整片编码前 | 修滤镜/源锚点；保留 ASR/内容决定，不启动整片 |
| 成片源相对时序 | 临时 MP4 完成、正式发布前 | 保留旧已验收版本；只修失败分支，不靠截尾/平移音轨凑时长 |
| 播放入口身份 | HTML 或附件发出前 | 比较实际字节，不只改 config；错误入口不宣布成功 |

`render_approved_full_preview.js` 已把源时序 CLI 放在临时 MP4 → rename 之间。自定义渲染器、模式 C 初版和最终包装也必须执行相同门槛，不能因未走该脚本而省略。

## 轻量与缓存

- 不重复转录：源音频不变，只改视频变速/镜像/入口时复用 ASR；改变剪辑或倍速则重建对应音频时间映射。纯封装或已证明音轨相同的版本不重跑 ASR。
- 缓存键包括源内容指纹、EDL、speed、filter graph、字体/字幕相关参数、工具版本；不能只认文件名。改字幕只失效字幕主体，改封面只失效封面，改镜像/B-roll只失效相关画面及其视觉验收。
- 源画面特征按源内容指纹和参考变换缓存，每个源首次提取一次；后续复验复用。静态/低置信度结果进入局部人工复核，不扩大成整片重查，不放松阈值假装通过。
- 子 agent/小模型负责独立候选和局部复核；主会话负责唯一 EDL、含义、切点、最终放行。没有可用小模型时直接完成，不为模型选择阻塞。
- API 报明确欠费、余额不足或服务停用时立即告诉用户；授权错误、限流、网络错误分别处理。不能把 `45000030` 自动当欠费或并发过高；充值恢复后实测一次，再恢复并发。

## 保留批注与版本切换

- 版本化 MP4 + 对应 EDL + 源时序报告 + 字幕报告作为一个交付版本；验收报告必须对应当前媒体和时间线指纹。
- 服务启动参数可能绑定旧视频，即使 `/api/config` 新了也仍会播放旧版。启动器必须核对实际 `/video` 字节，手动或其他播放器须从实际 `video.currentSrc` 取得 URL 再验。
- 有 queued/running 精剪回调时，不覆盖它读取的媒体、映射或活动配置，不强杀进程，不开两个共享同目录的可写批注服务。新版先做独立只读入口；任务结束后受控切换并保留不可变提交和活动批注。
- 来源时间线变更会使批注坐标失效：先保存快照并重新映射，不能把旧坐标直接套到新片。

## 可复用执行提示

```text
按 AI剪口播 的“多视频Preview快路径-v2”执行：素材只做快速异常检查；唯一音频按本地资源限额转写；小模型/子agent仅产候选，主会话冻结唯一源EDL。确认顺序后直接继续，不等第二次开始。字幕音频链与实际渲染长段小样并行，全部通过后编码Preview；按原片PTS核对段内音画，最后验证播放器实际媒体哈希。失败只返修相关分支，保留原片、缓存、批注和已验收版本。不得用时长相等、ASR对齐或网页能打开替代口型/版本检查。
```
