# 附加指令与真正可执行的参数

适用：用户说“用AI剪口播”后追加速度、气口、字幕、封面、聊天图、DB方法、跟随镜头或交付条件。先解析当前追加指令，不重新执行完整制作流程。

## 1. 先形成最小变更单

记录 `用户原话 → 项目/版本/时间基准 → 字段与单位 → 实际消费者 → 受影响阶段 → 验收`。优先级：当轮明确指令 > 本片已确认设置 > 所选模式默认 > 通用默认。冲突必须显式解决，不以新默认覆盖既有项目。保留原声、正文、笑声、时序及其有效证据中未被点名改变的部分。

参数分四类：
- **可执行参数**：真实脚本读取字段，且改变字段能改变输出。
- **项目适配参数**：只在指定项目脚本生效，使用前核对消费者。
- **规则/元数据**：目前仅供Agent读，禁止称为改JSON就能完成。
- **语义判断**：内容取舍、身份匹配、表演完整性；只将判断结果落入确定性字段，不用数值阈值替代判断。

## 3. 参数修改与失效

- 字体、字号、位置、阴影、封面：重建受影响文字/图层和样图。只有绑定同版codec/时钟的已验证局部splice才能复用视频码流，否则按现有执行器编码；如实报告，不说“零渲染”。
- 文字内容：只修改对应asset；保护词组、人名、否定词。完整字幕只能烧入干净底片，不能覆盖旧烧字造成双影。
- 气口、速度、删句、重排：唯一时间线owner串行合成。其他领域可准备，冻结新时基后才最终绑定。
- 文件名、链接、发布入口：只修入口，不重新转录/渲染。
- JSON字段没有消费者：标记“待接入”，不要创建看似完整却不生效的伪参数。可在既有owner中作小型扩展并运行变异测试，不另造万能框架。

## 4. 每日增量复盘

每日北京时间00:00的AgentsDock任务复盘刚结束的自然日；首次复用2026-10-13近月审计。它记录已覆盖源和待补日期，不重复扫描已验素材；无新增证据时不改skill。按Preview复盘规范读取不可变提交和真实验收，只有明确全局要求或完成且验收的重复案例才成为默认。每个新增参数要有消费者、参数变异测试和旧项目兼容测试。修改历史成片/切换当前Preview不是每日复盘的默认动作。
