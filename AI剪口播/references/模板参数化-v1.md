# 模板参数化 v1

## 目录

入口与边界；命令；项目参数；真实失效与恢复；验收与状态；复用提示词。

## 入口与边界

固定批准的干净底片、字幕和字体，改变包装而非剪辑内容。沿用原声、PTS与速度，不使用已烧字幕的成片，不转写、不重剪、不应用atempo/setpts。完整制作/角色/封面/聊天/B-roll规则仍由原领域owner决定。

真实工具是 `scripts/template_package.py`：Python3 + Pillow + fontTools + FFmpeg/libass。先核实安装与字体，不联网下载或安装KB/HyperFrames。第一版底片要求一条视频、一条音轨，1080×1920、方形像素、实际CFR30、视频零起始、音画起点同tick、显式BT.709 SDR，无旋转。HDR、未知色彩或其他规格回现有严格转换/制作链明确处理，不隐式裁切、贴标签或丢音轨。

模板 `assets/templates/peter-talking-head-v1.json` 沿用当前白色得意黑字幕：字号76，位置(540,1360)，黑色柔和阴影。字体以传入的真实文件为准，检查内部名称和实际字形覆盖。SRT原文、顺序和显式换行保持；最多2行，越界/遮挡/超长文本报错回字幕owner，不擅自缩字或改内容。

## 命令：构建 → 样张 → 输出

以安装后的skill根目录运行，或用绝对脚本路径。`FONT`指已确认字体文件；`BASE.mp4`和`CAPTIONS.srt`必须来自同一批准时间线。

```bash
SKILL="$HOME/.codex/skills/AI剪口播"
FONT="$HOME/.codex/skills/douyin-captions/assets/fonts/SmileySans-Oblique.ttf"
python3 "$SKILL/scripts/template_package.py" build \
  --video BASE.mp4 --srt CAPTIONS.srt --font "$FONT" \
  --output-dir package-v1
python3 "$SKILL/scripts/template_package.py" snapshot \
  --package package-v1/package.json --at 0.5 1.2 2.5 \
  --output-dir snapshots-v1
python3 "$SKILL/scripts/template_package.py" render \
  --package package-v1/package.json --profile preview --output preview-v1.mp4
# 样张、短片与适用的内容/视觉检查通过后再输出master。
python3 "$SKILL/scripts/template_package.py" render \
  --package package-v1/package.json --profile master --output master-v1.mp4
```

示例时间只适用于长于2.5秒的片；实际选开头/中段/末段及变更页，时间必须落在源片内且对齐30fps整数帧。snapshot输出1080×1920，render preview为540×960，master为1080×1920。snapshot保留非零字幕时间，同一profile画面才能做对应帧比较；低清与高清检查同样式比例，不要求不同分辨率逐像素相同。

## 项目参数：只改JSON

`build`输出：`style.json`（本项目冻结参数）、`captions.ass`（生成物）、独立字体资产、`package.json`（输入与生成资产SHA/媒体身份）。生成ASS不用手改。

写本项目 `overrides.json`：

```json
{
  "captions": {
    "font_size": 64,
    "y": 1280
  }
}
```

然后从已解析项目样式重建新版本：

```bash
python3 "$SKILL/scripts/template_package.py" build \
  --video BASE.mp4 --srt CAPTIONS.srt --font "$FONT" \
  --preset package-v1/style.json --overrides overrides.json \
  --output-dir package-v2
python3 "$SKILL/scripts/template_package.py" snapshot \
  --package package-v2/package.json --at 1.2 --output-dir snapshots-v2
```

允许字段：`captions.font_size/x/y/primary_color/shadow_opacity/shadow_offset/shadow_blur`；`protected_regions`为本项目实际脸、手势、聊天截图等避让框，格式`[{"x":0,"y":0,"width":100,"height":100}]`。坐标按1080×1920基准，预览自动缩放。未知字段、非有限数字、文本出界、避让框交叠直接失败；没有避让框不代表工具检测了人脸。

`shadow_opacity`是0–1可见度，不是ASS透明度；默认111/255，ASS alpha为144（`&H90000000`）。不改既有全局字幕字体默认，不把本片坐标写到canonical preset。

## 真实失效与恢复

| 改动 | 重做 | 复用 |
|---|---|---|
| 字号/位置/颜色/阴影/避让框 | 新build、变化页样张、包装编码 | 底片、原声、EDL、源转录 |
| 字幕文字 | 先用字幕owner/asset补丁改SRT；新build | 未变timing/原声/时间线证据 |
| 字体 | 新build、字符覆盖/样张、包装编码 | 底片与内容 |
| 正文/速度/剪点 | 回内容owner，重建批准底片及字幕映射，再build | 依赖未变的源ASR和样式 |
| 仅附件/网页入口 | 修实际发布入口 | 已验媒体和package |

- 对底片/字幕/字体与生成资产用内容SHA判身份，不用文件名、size/mtime误命中。build前后身份变化不发布；snapshot/render发现过期资产就要求新build。
- 原preset后来更新不使已经冻结的项目style自动变样；只有显式新build才采用新参数。
- 每次输出新目录/MP4；冲突立即报错。错误保留，不覆盖旧版、不同步改正在运行的Review或`active_release`。
- 当前render仍对整段包装画面编码，音轨copy；snapshot无需整片视频编码。这里没有持久GOP/片段渲染缓存，不承诺改字零渲染。
- 不把完整`captions.ass`传入旧Review的增量overlay，避免重复烧字；若需更新当前Review，使用其受支持的项目/候选发布机制与对应版本验收。

## 验收与状态

1. build检查源规格与逐帧PTS、SRT顺序/正时长/无重叠/边界、ASS厘秒量化后的时长、字体与测量布局。`packaged`只代表资产完成。
2. snapshot复核同版身份，保留非零时间出PNG；抽看文字真实字形、位置、实际避让，不能只看尺寸或白色像素框。中文方框视为失败。
3. render复制音轨，视频沿用时间轴；完整解码并比较输出/源每帧PTS及音频packet内容/PTS/DTS/时长，发布前再核输入身份。`technical_verified`且`visual_approved=false`只代表技术门，不冒充内容或视觉批准。
4. 继续执行本片真实变化对应的人工看听、源相对同步和交付门。封面前三帧、片尾、人物/聊天布局不在此工具实现范围内，仍按既有合成/领域链完成后再验收。
5. 记录build、snapshot、encode、technical QA及总时间。合成小样的秒数不外推真实口播整片，更不替代请求到交付时长。

## 复用提示词

```text
用AI剪口播的模板参数化入口：底片、SRT、字体已确认。
只把字幕字号改64、y改1280，其余样式保持；写项目overrides JSON。
从前版style重新build到新目录，先看变化页snapshot，再输出预览/正式包装版。
保留原声、时间轴、速度、笑声；零ASR、零重剪、零再次提速。
技术通过不自动批准视觉或切换Review；按本片真实变更验收后再交付。
```
