| 层 | 复刻参数 |
| --- | --- |
| 发布规格 | 1080×1920、30fps CFR、H.264 high、yuv420p、AAC 48kHz，MP4 faststart；参考编码 CRF16、AAC160k |
| 背景 | 原片抽静态帧，缩放裁切填满画布并模糊、压暗；不复制参考片背景到新素材 |
| 双人正文 | 完整横版画面缩为1080×608，x=0、y=650；保留双人不裁掉任一角色 |
| 上方说明 | 两行黄色 #FDFA87，Source Han Sans CN Heavy 54，x=60、y=150/222，黑描边2；阴影3/3、黑65%；说明文字依据本片事实确认，不把说明当作事实证明 |
| 主标题 | 得意黑96，白字，两条语义行，水平居中，y=350/465；阴影3/3、黑65%；标题逐片确认 |
| 字幕 | 得意黑76，白字，无描边；ASS内部字体名 `Smiley Sans Oblique`；中心(500,1360)，独立黑影中心(500,1365)，blur5，黑色Alpha50（ASS `&H50000000`） |
| 角色贴片 | 得意黑30，白字，无描边；左右中心(215,1100)/(840,1095)，独立黑影y+4、blur4、Alpha50；开头0–8s，短正文截至正文末尾；逐片核对身份与左右角色映射 |
| 封面与片尾 | 封面前5帧（30fps），现有固定片尾58帧；片尾保持原生竖屏，不叠正文标题、字幕或贴片；正文已有片尾时不重复追加 |
| 正文与速度 | 继承最新已确认正文和speed manifest；本路径只做后处理，不重剪、不强行再次1.3x；新粗剪仍使用原流程默认 |

背景模糊与暗度以新素材抽帧回读为准；批准脚本输入是已生成静态背景，未记录其滤镜数值，禁止声称某个模糊半径已获用户确认。

## 执行与最小验收

1. 绑定最新已确认正文、EDL、speed manifest 与角色映射；记录 `visual_profile=car-dialogue-v1`，默认后处理为字幕、封面、固定片尾及正确发布规格。
2. 由 `douyin-cover` 冻结本片标题语义行与封面；由 `douyin-captions` 输出字幕；由 `xiaolan-broll` 输出角色贴片。将本表参数作为本项目样式覆盖，不修改这些 skill 的其他形式规则。
3. 字体用内部名 `Smiley Sans Oblique` 并检查 libass 无 fallback；正文无已确认速度时先核实输入，不把烧字参考成片再变速。
4. 编码前做1秒冒烟样片；回读标题、左右人脸、角色贴片、字幕、背景和安全区。完成后检查第1/5/6帧、正文中段、8秒贴片退出、正文转片尾与片尾帧；ffprobe核对规格并解码。

可复用任务指令：

```text

标题用本片确认文本，角色文案仅在确认同素材同角色后复用。
将参数交给封面、字幕、角色贴片现有领域skill；加5帧封面与既有58帧固定片尾，
先核验字体和1秒样片，再输出1080×1920 30fps H264/AAC并回读。
```
